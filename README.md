## Hi there!

I'm a Kyiv-based software engineer who switched to IT when the war started, with a background in sales and marketing and a bachelor's degree in Applied Physics. It was a long way to software engineering, but not a random choice, since I've enjoyed programming since school and did it a lot during university.

I enjoy working on both sides: applications and developer experience tools. I had the pleasure of being part of the Developer Experience team at Toptal, where I got to know this field and loved it.

I'm not a fan of vibe coding. I'm a bit of an old-school guy in the sense that I like to code myself and learn new things the old way, by reading books and documentation and writing some throwaway code just to practice, with all the struggles of not understanding things and debugging.

I use AI on the job, but not from the position of a reviewer-bottleneck. I use it to help me investigate codebases faster to gain an understanding myself. Then I design the solution myself and implement it myself. AI helps me with repetitive changes and reviews.
